pdfdol.bundle#

Bundle several PDFs into one, with a contents page, per-document headers and bookmarks.

concat_pdfs just joins documents. bundle_pdf_bytes keeps track of which page each document starts on while joining, which is what makes these possible:

  • toc: a contents page (several pages if needed) whose lines link to the documents’ first pages;

  • doc_header: a band naming the document, added above its first page, so no content is covered;

  • outline: one bookmark per document.

Rendering text uses reportlab, imported lazily: without toc and doc_header, only pypdf is used.

>>> import io, pypdf
>>> def blank(n, w=200, h=300):
...     writer = pypdf.PdfWriter()
...     for _ in range(n):
...         _ = writer.add_blank_page(width=w, height=h)
...     buf = io.BytesIO(); _ = writer.write(buf); return buf.getvalue()
>>> out = bundle_pdf_bytes({'a.pdf': blank(2), 'b.pdf': blank(1)}, outline=True)
>>> reader = pypdf.PdfReader(io.BytesIO(out))
>>> len(reader.pages), [o.title for o in reader.outline]
(3, ['a.pdf', 'b.pdf'])

Join PDFs, optionally adding a contents page, document headers and bookmarks.

Parameters:

  • items (Mapping | Iterable) – {key: pdf_bytes} or an iterable of (key, pdf_bytes), in order.

  • toc (bool | Callable[[list, str], Union[bytes, tuple]]) – True for the default contents page (render_contents_pdf), or a TocRenderer callable (entries, title) -> bytes | (bytes, link_rects).

  • doc_header (None | bool | str | Callable[[str], str]) – Text of the band added above each document’s first page. True -> the key; a format string using {key}, {start_page}, {n_pages}; or a callable key -> str.

  • outline (bool) – Add one bookmark per document.

  • title (str | None) – PDF title metadata; also the contents page title if toc_title is left at its default.

  • toc_title (str) – Title of the contents page.

  • header_height (float) – Height in points of the header band.

Return type:

bytes

>>> import io, pypdf
>>> w = pypdf.PdfWriter(); _ = w.add_blank_page(width=200, height=300)
>>> buf = io.BytesIO(); _ = w.write(buf); one = buf.getvalue()
>>> out = bundle_pdf_bytes({'a.pdf': one, 'b.pdf': one}, toc=True, doc_header='{key}')
>>> reader = pypdf.PdfReader(io.BytesIO(out))
>>> len(reader.pages)  # 1 contents page + 2 documents
3
>>> float(reader.pages[1].mediabox.height)  # 300 + header band
330.0

>>> buf = io.BytesIO(); _ = w.write(buf)
